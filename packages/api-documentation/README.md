# AgentFactory API Docs

English | [中文](./README-ZH.md)

A list of AgentFactory public APIs, allowing users to programmatically execute many of the same tasks as the same in the GUI.

To run this standalone:

1. Spin up AgentFactory server:
    ```sh
    cd Alexo-Agent-Factory
    pnpm start
    ```
2. Start API Docs server:
    ```sh
    cd packages/api-documentation
    pnpm start
    ```

To run in dev mode:

```sh
cd Alexo-Agent-Factory
pnpm dev
```

Docs will be served on: `http://localhost:6655/api-docs`
