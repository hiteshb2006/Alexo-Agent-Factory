# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities in AgentFactory privately by emailing **security@alexocloudai.com**. Do not open public GitHub issues for security problems.

Include as much detail as you can: affected version, steps to reproduce, impact, and any proof of concept. We will acknowledge your report, investigate, and keep you informed while a fix is prepared.

## Supported Versions

Security fixes are applied to the latest release on the `main` branch.
